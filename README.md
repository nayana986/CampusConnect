# 🎓 CampusConnect – Smart Peer-to-Peer Campus Networking Platform

## 📌 About the Project
CampusConnect is a web-based campus networking platform developed using Java Spring Boot, MySQL, HTML, CSS, and JavaScript. It helps students connect with other students, search student details, explore campus networks, and view academic performance.

## ✨ Features
- Student Registration
- Student Directory
- Student Profile View
- Edit and Delete Student Details
- Student Search using HashMap
- Student Search using Binary Search Tree (BST)
- GPA Leaderboard
- Student Connections Management
- Campus Network Visualization
- Shortest Path Finding using BFS
- MySQL Database Integration

## 🛠️ Technologies Used
- Java
- Spring Boot
- MySQL
- HTML
- CSS
- JavaScript
- Gradle

## 🧠 Data Structures and Algorithms
- HashMap – Fast student searching
- Binary Search Tree – Student search and traversal
- Graph – Student connection management
- Breadth First Search (BFS) – Shortest path finding
- Merge Sort – GPA leaderboard sorting

## ⚙️ How to Run the Project

1. Clone this repository.
2. Open the project in VS Code or IntelliJ IDEA.
3. Configure your MySQL database connection in `application.properties`.
4. Create a MySQL database named `campusconnect`.
5. Run the Spring Boot application:

```bash
./gradlew bootRun
```

For Windows PowerShell:

```powershell
.\gradlew.bat bootRun
```

6. Open your browser and visit:

```text
http://localhost:8080/
```
